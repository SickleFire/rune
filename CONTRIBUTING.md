# Contributing to Rune

We welcome contributions to Rune! 

## Quick Start

1. **Fork & Clone** the repository.
2. **Create a branch**: `git checkout -b feature/your-feature`
3. **Make your changes** and test: `cargo test`
4. **Commit & Push**: `git commit -am 'Add amazing feature'` and `git push origin feature/your-feature`
5. **Open a Pull Request**.

## Guidelines

- Keep code clean and idiomatic Rust.
- Add tests for new features or bug fixes.
- Ensure `cargo check` and `cargo test` pass successfully.
