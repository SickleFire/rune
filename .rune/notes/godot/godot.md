# Godot Integration Reference (`godot/`)

Contains C# scripts, GDScript files, and plugin configuration for Godot engine integration:
- `godot/RuneBridge.cs`: C# bridge for Rune integration within Godot.
- `godot/RuneBridge.gd`: GDScript helper script for editor/runtime hooks.
- `godot/RuneBridgePlugin.cs`: Godot editor plugin implementation.
- `godot/plugin.cfg`: Godot plugin metadata configuration.
